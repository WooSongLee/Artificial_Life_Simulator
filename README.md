# Artificial Life Simulator

브라우저에서 실행되는 3D 인공 생태계 시뮬레이터다. 사용자는 가상의 월드를 관찰하고, 그 안에서 에너지를 관리하며 학습·교배·사망하는 개체들을 실험한다.

차트와 통계는 실제 시뮬레이션 값만 표시한다. 학습하거나 진화하는 것처럼 보이도록 결과를 꾸며내지 않는다.

## 기술 스택

| 구분 | 기술 |
|---|---|
| Language | TypeScript |

| 3D | Three.js, React Three Fiber, Drei |
| State | Zustand |

| Persistence | IndexedDB |


## 조작

- 마우스 드래그: 카메라 회전
- 휠: 확대 / 축소
- 개체 선택: 카메라가 그 개체를 따라간다. 좌측 카메라 설정에서 끌 수 있다
- 좌측 패널: 월드(지형 프리셋·Seed 포함), 학습, 보상, 진화(유전 On/Off), 레이어, 오브젝트 배치
- 하단 컨트롤: Play / Pause / Reset, 1x–100,000,000x 로그 속도
- 중앙 탭: World, Simulation, Learning, Evolution, Experiments
- 개체를 클릭하면 상태, Genome, Q-Table 요약을 볼 수 있다

새로고침하면 마지막 세션을 복원한다. 실행 중이던 실험은 `paused`로 돌아온다.

## 아키텍처

시뮬레이션 계산, 학습, 진화, 3D 렌더링, UI를 분리한다.

```text
src/
  simulation/   # 고정 시간 스텝, 이동, 대사, 먹이, 월드 생성
  learning/     # 관찰 인코딩, 보상, Tabular Q-Learning, 에이전트별 Q-Table
  evolution/    # Genome, 교배, 돌연변이, 세대 기록
  experiments/  # 스냅샷, IndexedDB, JSON 검증, 실험 비교
  store/        # Zustand. 틱마다 월드 스냅샷만 갱신하고 Q-Table은 밖에 둔다
  hooks/        # 시뮬레이션 루프, 세션 복원, 스로틀된 통계
  components/   # 레이아웃, 패널, 3D 월드
```

- 시간은 `tick × 0.05s`다. 프레임률과 독립이다.
- 고속은 프레임당 스텝 수와 14ms 예산으로 제한한다.
- 학습 차트는 1초마다 샘플하고 최근 180개만 유지한다.
- 3D 메시는 개체 ID 기준으로 유지하고, 위치/회전은 `useFrame`에서 스토어를 읽는다.
- 분석 패널 통계는 약 150ms마다 갱신한다.

InstancedMesh와 Web Worker는 넣지 않았다. 개체는 색, 선택, 행동 표시, 교배 표시가 제각각이고, 기본 규모(1–50)에서 Q-Table 갱신은 메인 스레드 예산 안에 들어온다. 병목이 측정되면 그때 도입한다.

## 학습 알고리즘

각 개체는 자신만의 Tabular Q-Table을 가진다.

1. 관찰을 13개 이산 특징으로 인코딩한다. 에너지, 허기, 먹이 방향, 먹이 거리, 전방 장애물, 현재/전방 지형, 근처 채집 자원, 근처 도구, 장착 도구, 근처 개체 방향/거리, 체력.
2. ε-greedy로 행동을 고른다. 탐험 시 전진에 가중치를 둔다.
3. 행동 후 보상으로 Q 값을 갱신한다.

```text
Q(s, a) ← Q(s, a) + α (r + γ max Q(s′, a′) − Q(s, a))
```

- α와 초기 ε는 개체의 Genome이다. Strength, Aggression, Caution, Tool Affinity도 Genome이다.
- Aggression/Caution은 정책 선택 점수의 작은 선천적 편향이다. Q 값을 덮어쓰지 않으며, 편향 상한은 0.25다.
- γ, ε 하한, ε decay는 좌측 학습 설정이다.
- 학습을 끄면 Q-Table과 ε이 고정되고 현재 정책만 평가한다.
- 기본 보상: 섭취 +10, 채집 단위당 +2.5, 도구 습득 +1, 실제 공격 피해량 × 0.3, 공격 실패 −0.4, 받은 피해량 × −0.3, 방어로 줄인 피해량 × 0.2, 실제 도주 +0.7, 섭취 가능 먹이를 두고 이동 −1, 충돌 −2, 사망 −20, 효율적 휴식 +0.4. 탐색 이동 자체에는 페널티가 없다.

## 시뮬레이션 규칙

- 개체는 이동·회전·섭취·휴식·도구 습득·채집·공격·방어·도주를 하며 에너지와 허기가 변한다. 지형은 이동 속도, 에너지 소모, 시야, 은신, 자원 분포에 영향을 주고 물은 통과할 수 없다. 에너지가 낮으면 체력이 줄고, 체력 0 또는 수명 도달 시 사망한다. 전투로 체력이 0이 되면 `combat` 사망이다.
- 섭취 가능 거리의 먹이는 현재 행동과 관계없이 먹는다. 베리 덤불과 뿌리 패치는 별도 채집 자원이며 GATHER로만 줄어든다.
- Basket은 베리 채집량을 늘리고, Digging Stick이 있어야 뿌리를 캘 수 있다. Spear는 공격 사거리와 피해를 늘리고, Shield는 방어 성공 시 피해를 더 줄인다. 성공 사용 시 도구 내구도가 줄고 0이면 파손된다. 사망하면 장착 도구는 월드에 떨어진다.
- 유전은 기본 꺼짐이다. 켜면 성욕이 찬 성숙 개체가 가까이 올 때 교배한다. 교배 중에는 에너지가 줄고, 끝나면 성욕이 충족되며 자식이 태어난다.
- 자식 Genome은 uniform crossover 후 유전자별 돌연변이다. 세대는 `max(부모 세대) + 1`이다. Q-Table 상속은 Genome 상속과 분리되어 기본 꺼짐이다.
- 생존 수가 Population Limit 이상이면 자식은 태어나지 않는다.
- 생존 개체가 없으면 시뮬레이션은 `ended`가 된다.
- Reset은 월드, 학습 뇌, 통계, 선택 상태를 다시 만든다. 실행 중 바꾼 월드 구조는 Reset 때 적용된다.

## 향후 확장 계획

- 프로파일링 후 50–100개체 규모와 InstancedMesh / Worker 재검토
- 상태 공간이 커지면 PPO 등 다른 학습 알고리즘 검토
- 서버 동기화가 필요해지면 실험 저장 백엔드

초기 범위에 없는 것: LLM 에이전트, 사실적 생체역학, 멀티플레이어, 계정/결제, 현실 인간 행동 예측.

## 알려진 제한

- 데스크톱 우선이다. 800×560 미만에서는 가로 스크롤이 생긴다.
- 월드 Seed와 지형 프리셋은 좌측 설정에서 바꿀 수 있다. 같은 Seed와 프리셋은 같은 지형 배치를 만든다.
- 고속(수천 배 이상)에서는 프레임 예산 때문에 요청한 배속보다 적게 진행될 수 있다.
- Q-Table 상속은 기본 꺼짐이다. 새 세션의 유전도 기본 꺼짐이다. 유전 특성과 학습된 지식은 다른 개념이다.
